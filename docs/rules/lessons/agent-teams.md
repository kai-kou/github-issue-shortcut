## L-121: サブエージェントの所見が最終テキストの上書きで消え、空の戻り値を「指摘なし」と誤読する（2026-07-25）

**パターン**: 観点別フレッシュ文脈レビュー（`code-review` スキル Layer 1）のファインダーを `Agent`
ツールで起動すると、十分なトークン・ツール呼び出しを消費しているのに戻り値が
`Done.` / `(no action needed)` / `(重複)` / `End.` の一言だけになり、所見を受け取れない
（Issue #140・PR #136 / #139 で合計 55 万トークンが成果物なしで消えた）。

**根本原因（3 層）**:

| 層 | 内容 |
|----|------|
| 直接原因 | 親が受け取るのは **サブエージェントの「最後の」assistant テキストのみ**。所見は先行ターンに出ていたが戻り値にならない |
| 中間原因 | 報告を終えた後もエージェントのターンが続き、相槌（`完了。` → `完。` → `End.`）が最終テキストを上書きする。継続の駆動要因は 2 つ観測されている: ① 入力なしの自発的なターン継続（再現ログでは相槌 6 ターンの間、対応する入力エントリがない）② ハーネスの継続プロンプト注入（`[Your previous response had no visible output...]`） |
| 根本原因 | スキルの受け渡し規約が「最終メッセージ本文で返す」前提で、成果物の永続化（ファイル / ホワイトボード）を義務づけていなかった。`discussion-review` はホワイトボードで同じ事故を回避できていたのに Layer 1 だけ揮発チャネル依存だった |

**実測（本セッションでの再現・2026-07-25）**: 調査用サブエージェント 1 本（`general-purpose` ・
`model=haiku` ・「テキストのみで報告」指示）が 74k トークンを消費し、所見 807 文字を先行ターンで
出力した後、相槌を 15 ターン重ねて戻り値は `End.`。`SendMessage` でファイル書き出しを指示して
再開すると、戻り値は `(Complete.)` だったが **ファイルは 29 行の完全な内容で残っていた**
（＝作業は行われている。失われるのはテキスト経路だけ）。

**未確定の範囲（過度に一般化しない）**: 再現は haiku・縮退した出力縛りの条件で、より上位モデルでの
発生率は未測定。また元事象（#136 / #139）のトランスクリプトは別セッションのため参照できておらず、
そちらが同じ「相槌上書き」だったか、`ReportFindings` 経路（ホスト UI へ報告し親に届かない・仕様上
テキストへ重複出力しない）だったかは区別できていない。**どちらの経路でも対策（ファイル受け渡し +
受領検証 + `ReportFindings` 禁止）は有効** なため対策は共通化したが、再発時の診断では両方を疑う。

**対策（昇格先）**:
- `.claude/skills/code-review/SKILL.md` Step 1（ファインダーへ `{RUN_DIR}/{スラグ}.md` への Write を義務づけ・
  最終メッセージは `WROTE:` 1 行・`name` 付き起動）/ Step 1.5（受領検証と回復手順）/ Step 2（反証担当にも同規約）
- `tools/check_review_findings.py`（**機械ゲート**: 所見ファイルの存在・非空を判定し、欠落時は
  回復手順を stderr に出して exit 1。`--self-test` 付き）
- `docs/rules/agent-team.md`「サブエージェント成果物の受け渡し規約」・`agent-team-summary.md`（Hot サマリー）
- `docs/rules/problem-investigation-protocol.md`（Step 3 並列調査）・
  `.claude/skills/self-improvement-loop/SKILL.md`（発見モード Step 1）— 同型の並列起動箇所にも規約を適用

**禁止 / 推奨**:

```
❌ 空・一言の戻り値を「指摘なし」として報告に載せる（未実施を成果ゼロと言う捏造・L-113）
❌ サブエージェントに ReportFindings を使わせる（ホスト UI 向けで親セッションに届かない）
❌ 同じサブエージェントに「本文で再送して」と頼み直す（同じ経路なので同じく消える）
✅ 成果物はファイル / ホワイトボードへ書かせ、最終メッセージはパスと件数の 1 行だけにする
✅ 回収漏れは生トランスクリプト（`tasks/<agentId>.output` →
   `~/.claude/projects/<プロジェクト>/<セッションID>/subagents/agent-<agentId>.jsonl`）の
   assistant text ブロックを全件読んで回収する
```
